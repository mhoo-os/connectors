# Mhoo OS Connectors

[![Status: Documentation only](https://img.shields.io/badge/status-documentation_only-2563eb)](https://github.com/mhoo-os/connectors)

This repository is the future external connector layer for Mhoo OS.

It currently contains documentation only. Clover integration will use a Nango abstraction. No Clover credentials, legacy Clover tokens, provider calls, or production integrations are configured.

## Directories

- `clover/` — Clover integration requirements and boundaries.
- `nango/` — Nango abstraction and connector architecture.
- `docs/` — shared connector documentation.
